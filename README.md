# InventoryPro

React + Vite + Tailwind + Framer Motion + Three.js

```bash
npm install
npm run dev
```

- Qoldiq va operatsiyalar brauzerda (localStorage) saqlanadi. Tiklash: Reports → Tiklash.
- Ctrl+K — qidiruv. Sidebar'dagi "Show Demo" — avto-ko'rik.
- Backend ulanganda `src/data/warehouse.js` va `AppContext` dagi `OPERATE` API chaqiruvlari bilan almashtiriladi.
